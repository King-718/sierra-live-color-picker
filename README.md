# Live Color Picker for Sierra Chart

Live colour wheel for chart backgrounds - Only works on Background of the chart - drop down is there for future editions. 

**Download:** [LiveColorPicker-v0.1.zip](https://github.com/King-718/sierra-live-color-picker/releases/download/v0.1/LiveColorPicker-v0.1.zip)

## Install

1. Close Sierra Chart.
2. Unzip and copy `LiveColorPicker_2969_64.dll` into Sierra's Data Files Folder (**Global Settings > General Settings > Paths**).
3. Start Sierra and add **Live Color Picker** as a custom study.
4. In **Chart > Graphics Settings**, uncheck **Use Global Graphics Settings Instead of These Settings**.
5. Right-click the chart and choose **Live Color Picker...**.

Requires 64-bit Sierra Chart 2969 or newer.
