# Live Color Picker for Sierra Chart

Dark colour panel for Sierra Chart. One-click themes, Shuffle, and live colour for the background, candles, grid, text, price box, chart DOM columns and study colours (plots and colour inputs). Includes a guide for darkening Sierra's buttons, tabs and settings windows.

**Download:** [LiveColorPicker-v0.4.zip](https://github.com/King-718/sierra-live-color-picker/releases/download/v0.4/LiveColorPicker-v0.4.zip)

## Install

1. Close Sierra Chart.
2. Unzip and copy `LiveColorPicker_2969_64.dll` into Sierra's Data Files Folder (**Global Settings > General Settings > Paths**). Updating: replace the old file.
3. Start Sierra and add **Live Color Picker** as a custom study.
4. In **Chart > Graphics Settings**, uncheck **Use Global Graphics Settings Instead of These Settings**.
5. Right-click the chart and choose **Live Color Picker...**.

Requires 64-bit Sierra Chart 2969 or newer.
